# Floral assets

Drop image files in this folder and the invitation picks them up automatically —
no code change. If a file is missing, the app falls back to the drawn SVG
flowers in `src/components/Floral.jsx`.

| File | Where it appears | Suggested size |
|---|---|---|
| `corner.png` | Top corners of the cover, mirrored on the right | ~900 × 900 |
| `divider.png` *(optional)* | Between sections | ~1200 × 260 |
| `sprig.png` *(optional)* | Beside the closing message | ~400 × 600 |

## What to look for

- **PNG or WebP with a transparent background.** A white box behind the flowers
  will be obvious against the parchment.
- **Watercolour or painted style**, warm cream / blush / sage — that is what the
  reference invitations use and it matches the palette.
- **Roughly square** for `corner.png`, with the bouquet weighted toward one
  corner, since it is mirrored for the opposite side.
- **Under ~300 KB each.** These load on phones over mobile data at a wedding.
  Convert to WebP if a PNG comes out heavy.

## Licensing — read this

The client is *selling* these invitations, so the assets must be cleared for
**commercial use**. A "free for personal use" download is not enough.

Safe routes:

- **Freepik / Envato / Creative Market** — buy the commercial licence
- **Canva Pro** — commercial use included in the subscription
- **Commission an illustrator** — you then own it outright, and nobody else's
  invitations look identical
- **AI-generated** — check your generator's commercial terms first

Keep the licence receipt somewhere safe. If a client ever asks where the artwork
came from, you want to be able to answer.
